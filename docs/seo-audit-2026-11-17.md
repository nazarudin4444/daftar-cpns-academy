# Audit SEO 17 November 2026

## Temuan dan perbaikan

- Materi figural hanya tersedia lewat kontrol interaktif. Ditambahkan empat route publik: `/soal-tiu-figural`, `/soal-tiu-analogi-gambar`, `/soal-tiu-matriks-gambar`, dan `/soal-tiu-deret-gambar`. Setiap halaman memiliki panduan tersendiri, contoh bergambar, jawaban, dan pembahasan yang hadir dalam HTML server.
- `/alat-belajar`, `/persiapan-dokumen`, `/kisi-kisi-skd`, dan `/situs` tidak tercakup generator sitemap. Keempatnya kini memakai katalog metadata yang sama dan masuk sitemap.
- Canonical relatif dan preview sosial yang tidak lengkap pada halaman khusus disatukan melalui `contentHead`. Origin produksi mengikuti konfirmasi di `LAUNCH.md`.
- `/formasi-cpns`, `/jadwal-cpns`, dan `/panduan` sebelumnya tidak menyertakan JSON-LD. Structured data kini dikirim melalui head route, termasuk halaman khusus.
- Bank soal memiliki H1 tersembunyi tambahan. Hero tersembunyi tidak lagi dirender. Simulator memiliki pengantar dan H1 pada HTML awal sebelum pemulihan sesi browser.
- URL tidak dikenal sebelumnya mengembalikan HTTP 200. Pemeriksaan route kini dilakukan sebelum render sehingga respons menjadi 404. Dashboard tetap `noindex` dan tidak masuk sitemap.
- Ditambahkan tautan HTML dari footer, halaman TIU, bank soal, dan antarpanduan figural. Tidak dibuat ribuan halaman tipis dari variasi soal.
- Halaman publik mengizinkan preview gambar besar melalui `max-image-preview:large`. Tidak ditambahkan rating, tanggal verifikasi, atau identitas yang tidak tersedia.

## Pemeriksaan

`node scripts/audit-seo.mjs http://127.0.0.1:8080 .output-documents.local/seo-local.json`

Audit HTML server meliputi 29 URL sitemap, dashboard, redirect `/simulasi`, dan URL tidak dikenal: 32 pemeriksaan URL, tanpa temuan setelah perbaikan. Pemeriksaan mencakup HTTP, judul/deskripsi unik, canonical, robots, bahasa, H1, JSON-LD, dan gambar preview. Ini bukan pengukuran ranking atau Core Web Vitals.

Audit produksi sebelum push menemukan versi lama: masalah JSON-LD, H1 ganda, soft 404, dan empat halaman figural yang belum dipublikasikan. Perubahan lokal baru berlaku setelah deployment berhasil.

Pemeriksaan transport produksi: `https://www.daftar-cpns.com/` merespons 301 ke apex HTTPS. `http://daftar-cpns.com/` masih merespons 200, sehingga redirect HTTP ke HTTPS perlu diaktifkan pada hosting. Robots, sitemap, dan gambar preview sosial merespons 200 dengan content type yang sesuai.

## Pemeriksaan lanjutan setelah deployment

- Jalankan `npm run audit:seo -- https://daftar-cpns.com`.
- Periksa redirect HTTP dan alias www, serta respons aset preview sosial.
- Kirim sitemap melalui properti Search Console yang sudah diverifikasi pengguna; akses/verifikasi Search Console belum tersedia dalam sesi ini.
- Periksa halaman baru lewat URL Inspection dan ukur Core Web Vitals dari penggunaan nyata. Jangan menyamakan lolos audit HTML dengan jaminan indeksasi atau ranking.
